关于妙妙屋X

妙妙屋X 是妙妙屋的增强版，专注于远程服务器管理和 Xray 配置
什么是妙妙屋X

妙妙屋X（MMWX）是基于妙妙屋的增强版本，在保留原有订阅管理功能的基础上，新增了远程服务器管理、Xray 服务完整管理、证书管理、套餐管理等高级功能。

采用 Master-Agent 架构，主控端（Master）通过 WebSocket/HTTP 与远程服务器上的 Agent 通信，实现对多台服务器的统一管理。
架构概览

```
┌─────────────────────────────────────────┐
│           妙妙屋X (Master)              │
│                                         │
│  ┌──────────┐  ┌──────────┐  ┌───────┐ │
│  │ 节点管理  │  │ 用户管理  │  │ 证书  │ │
│  └──────────┘  └──────────┘  └───────┘ │
│  ┌──────────┐  ┌──────────┐  ┌───────┐ │
│  │ 订阅生成  │  │ 套餐管理  │  │ 模板  │ │
│  └──────────┘  └──────────┘  └───────┘ │
│                                         │
│         WebSocket / HTTP / Pull         │
└────────┬──────────┬──────────┬──────────┘
         │          │          │
    ┌────▼───┐ ┌───▼────┐ ┌──▼─────┐
    │ Agent  │ │ Agent  │ │ Agent  │
    │ Server1│ │ Server2│ │ Server3│
    │ (Xray) │ │ (Xray) │ │ (Xray) │
    └────────┘ └────────┘ └────────┘
```

与妙妙屋的区别
功能	妙妙屋	妙妙屋X
节点管理	手动添加/导入	手动 + 远程同步
远程服务器管理	-	Master-Agent
Xray 入站/出站	-	可视化管理
证书管理	-	ACME 自动化
套餐管理	-	流量套餐
订阅生成	12种客户端	12种客户端
用户管理	基础	增强（套餐绑定）
模板系统	V3 模板	V3 模板
